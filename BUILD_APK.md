# English Words 0.6 — исправленная сборка для GitHub Actions

## Установка исходников в репозиторий `0-6`

1. Распакуйте архив на компьютере.
2. Загрузите **содержимое** папки в корень репозитория `0-6` в ветку `main`, не сам ZIP и не внешнюю папку. Замените существующие файлы. Скрытая папка `.github` обязательно должна попасть в репозиторий.
3. Проверьте, что файл `.github/workflows/main.yml` совпадает с файлом в этом архиве. При загрузке в веб-интерфейсе GitHub скрытые папки иногда пропускают — если так, откройте существующий `main.yml`, выделите его содержимое, замените на код из архива и сохраните Commit changes.
4. Если в `.github/workflows` есть **другие** старые конфигурации сборки (например, `build-apk.yml`), удалите их, чтобы не запускать параллельные задания. Оставьте один `main.yml`.
5. Вкладка Actions → Build Android APK; сборка запускается автоматически после коммита в `main`. При необходимости используйте Run workflow.
6. Если будет зелёная галочка: откройте запуск → Artifacts → `EnglishWords-0.6-debug-APK`. Скачайте ZIP, распакуйте его; внутри будет `app-debug.apk`.
7. Если будет красный крестик, откройте job Build debug APK и пришлите лог первого красного этапа. Не пытайтесь угадывать следующую ошибку.

## Что исправлено

- Ошибка `Failed to find package 'tools'`: `android-actions/setup-android@v4` без устаревшего пакета `tools`.
- Ошибка `Minimum supported Gradle version is 8.9. Current version is 8.7`: установлен Gradle **8.10.2**; проект использует Android Gradle Plugin **8.7.3**.
- Полностью заменена конфигурация `main.yml`, чтобы исключить ошибки форматирования при ручном редактировании.
- Подключены Java 17, Android SDK 35, Build Tools 35.0.0, загрузка готового APK.

## Ограничения проверки

Проверена структура исходников, JSON иконки и синтаксис YAML. В текущей среде **нет установленного Android SDK/Gradle**, поэтому APK не компилировался здесь. Если обнаружится другая ошибка Kotlin/Gradle, её потребуется исправить по новому журналу.

Версия 0.6 продолжает использовать системное распознавание речи Android; полная офлайн-автономность будет в следующих версиях.
