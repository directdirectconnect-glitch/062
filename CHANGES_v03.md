# English Words v0.3 — обновление интерфейса

- Крупное английское слово на отдельной карточке.
- Русская подсказка произношения из `words.json` под английским словом.
- В направлении RU → EN подсказка скрыта до ответа.
- Настройки в отдельной сворачиваемой панели «Меню».
- Крупная кнопка микрофона, повтор слова, кнопки самооценки и пропуск.
- Индикатор прогресса, счётчик и статистика.
- Исправлена ошибка проверки ответов в смешанном режиме: используется `questionDirection`.
- Защита от двойной оценки одного слова.
- Сохранён прежний applicationId и файл прогресса, чтобы обновление не сбрасывало статистику.

## Сборка
Загрузите содержимое каталога `English1000Android` в корень репозитория GitHub, заменяя существующие файлы. Затем Actions → Build Android APK → Run workflow. APK будет в Artifacts.

Это исходный код, не собранный APK. Проект не был скомпилирован в текущей среде. В словаре 1000 предварительных записей; качество переводов и транскрипции требует отдельной проверки.
