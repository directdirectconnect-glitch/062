# English Words Android 0.6 — тестовая версия

Исходники приложения для Android: Kotlin, Android Gradle Plugin 8.7.3, Gradle 8.10.2, Java 17, compileSdk 35, minSdk 26.

## Возможности

- Английские слова с русским переводом и подсказкой произношения русскими буквами.
- Строгий светлый интерфейс, красный значок приложения и скрываемое меню настроек.
- Тренировочные блоки по 10, 20, 30 или 50 слов.
- Тренировка EN → RU, RU → EN и смешанный режим.
- Голосовой ответ через SpeechRecognizer Android или ручная оценка.
- Локальная статистика и повторение ошибок.
- 1203 записи словаря, не прошедшие полной корпусной верификации.

**Ограничение:** распознавание речи зависит от системной службы Android и может требовать интернет. Полностью автономная версия ещё не готова.
