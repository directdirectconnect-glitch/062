# English Words — Android-приложение для изучения английских слов

> **Главный документ проекта:** [LEARNING_FOUNDATION_5000.md](LEARNING_FOUNDATION_5000.md) — согласованная учебная стратегия: **3 000 слов — обязательное бытовое ядро; 5 000 — целевой словарь**. Главная цель — самостоятельно понимать, вспоминать, произносить и использовать слова, а не просто просматривать карточки. Все следующие версии должны соответствовать этим правилам.

## Состояние разработки

- **Текущая экспериментальная ветка:** `develop/0.8.8-word-families`. Здесь разрабатываются монохромные темы (светлая / тёмная / системная), семьи слов и адаптивный интерфейс.
- **Ветка `main`** хранит более раннюю версию, а не все изменения из экспериментальной ветки.
- **Словарь:** 1 212 записей в `words.json` на дату утверждения стратегии. Это не 1 212 освоенных слов. Словарь ещё нуждается в корпусной и переводческой проверке.
- **Мобильная совместимость:** Android 8+ (API 26), обычные смартфоны и складные устройства Galaxy Fold. Полная проверка на физических устройствах ещё не завершена.
- **Офлайн:** словарь локален; доступность голосов и распознавания зависит от установленных компонентов Android. Встроенный Vosk пока не реализован.
- **Контроль качества:** успешная компиляция APK в GitHub Actions — не подтверждение того, что все функции работают на телефоне.

## Учебные принципы

1. Стандартный блок — 50 слов. Допускаются короткие блоки; до 500 **проверок** слов в день — возможность, а не обязанность и не гарантия освоения 500 новых слов.
2. Если есть ошибки, сначала повторяем проблемные слова; к новым блокам переходим после устранения ошибок.
3. Ведём отдельно результаты EN→RU и RU→EN; показ карточки и подсказки не означает знания.
4. У слова могут быть родственные слова, приставки и суффиксы. Они помогают учить, но учитываются как освоенные только после собственной проверки.
5. Отдельно анализируем повторные ошибки в **словах**, по грамматическим классам и темам; не объявляем неуверенные гипотезы фактами.
6. Первая основная цель — **3 000**, расширение — **5 000** качественных часто используемых слов.

## Сборка

Kotlin, Android Gradle Plugin 8.7.3, Gradle 8.10.2, Java 17, `compileSdk 35`, `minSdk 26`. GitHub Actions: `.github/workflows/main.yml`; отладочная сборка `:app:assembleDebug`. APK хранится в артефакте `EnglishWords-APK` соответствующего запуска.

Не удаляйте работающую версию приложения до проверки совместимости подписи APK и сохранности пользовательских данных.
