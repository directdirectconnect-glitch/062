## Исполняемый план
1. Создать журнал уникального запуска в `C:\EnglishWords-Windows-Lab\results\qa2-1000\`. Получить АКТУАЛЬНЫЙ статус физического ADB, версии пакетов и целевой активности. Проверить user profile/ANDROID_USER_HOME; не менять системный PATH.
2. Если пользовательский установщик ещё работает — не запускать повторно. Иначе использовать актуальный безопасный `Install-QA2-S20Safe.ps1`; проверить его PowerShell Parser на 0 синтаксических ошибок; вручную проверить скрипт и предполагаемые изменения. Разрешена только **новая установка** `.visual164qa2` после успеха CI, package/manifest, SHA256, apksigner. Не делать `adb uninstall`, `pm clear`, `adb install -r`, переустановку других пакетов.
3. Проверить доступность Android SDK tools `aapt` и `apksigner` (или эквивалентных официальных инструментов). При недоступности — BLOCKED с реальной причиной и безопасный фикс, не пропускать проверки.
4. Если QA2 установлен: smoke-test запустить активность, проверить UI/отображение русского перевода после «Не знаю», слова, 164 фотоматериала и перезапуск/сохранение прогресса. Документировать реальные уникальные ID слов, кадры, logcat и ошибки.
5. Реализовать `Run-S20-1000QA.ps1` или эквивалент: 20 блоков по 50 **разных ID**, контрольные точки 250/500/750/1000, ошибки/повторение не засчитывать дважды, устойчивое восстановление после остановки. Не выдавать случайные нажатия за проверенные ответы. Для каждого сценария PASS/FAIL/NOT_RUN; скриншоты, XML UI, trace и CSV/JSON уникальных ID.
6. Offline: проверить Wi-Fi и mobile data с документированным восстановлением предыдущего состояния даже при ошибке. EN/RU TTS и ASR должны быть отдельно NOT_RUN без реальной акустической петли; возможно тестирование при наличии фактического микрофона/колонки и записей.
7. Сохранить результаты в локальной `results\qa2-1000\`, публиковать в #19 краткие обезличенные отчёты с commit SHA, build run ID, пакетом, PASS/FAIL/NOT_RUN и количеством уникальных слов. Не публиковать серийные номера ADB, токены, личные данные и длинные logcat.
8. Согласовать `Invoke-Issue19.ps1` и Windows Task только после того, как подтверждён безопасный локальный runner. Любая самозагрузка или выполнение произвольного текста комментариев запрещены.

## Критерий готовности
Физический `PASS 1000/1000` только когда подтверждены 1000 разных слов на SM-G780G, скриншоты/логи 20×50 и восстановление состояния; отдельный статус для ASR/TTS. Если невозможно, точно назвать блокер и оставить `NOT_RUN` или `FAIL` по данным. Существующие приложения и данные не повреждать.
