# English Words — ускоренная параллельная разработка (10.11.2026)

## Базовая версия
`beta/0.9.5-unified` — интеграционная бета, не менять до проверки на устройствах. `main` не переключать без приёмки.

## Независимые потоки
1. `develop/0.9.6-stability`: сохранение состояния и ошибок блока, переключение «Изучать» / «Проверять» / «Спроси слово», узкий экран и раскрытый Galaxy Fold, жизненный цикл аудио.
2. `develop/0.9.7-offline-asr`: интеграция автономного ASR и моделей RU/EN без облачного fallback; отдельно проверить размер APK, лицензии, ABI и устройства Android 8+.
3. `develop/0.9.8-visual-vocabulary`: локальные иллюстрации, лицензии и атрибуция, сопоставление по стабильному ID слова, fallback без изображения, расширение и валидация словаря.

## Приёмочные ворота
- На каждой ветке: валидация assets, unit-тесты, сборка APK.
- Автоматический smoke-тест Android-эмулятора должен запускать APK и проверять три режима, без сети, паузы/возобновление и сохранение состояния.
- Не смешивать ошибку CI/эмулятора с доказанной ошибкой приложения. Сейчас test/0.9.5-emulator: сборка и JVM успешны, падает шаг Android 13 offline APK smoke test.
- Ручная проверка на Galaxy Fold и обычном смартфоне обязательна перед релизом.
- Не удалять установленную APK до проверки подписи обновления и сохранения прогресса.

## Ближайшая последовательность
1. Разобрать журнал падения emulator smoke test и стабилизировать тестовый конвейер.
2. Завершить ветку 0.9.6 с регрессионными тестами.
3. Независимо реализовать минимальный сквозной офлайн-ASR и локальные иллюстрации; не заявлять готовность до проверки.
4. Объединять только проверенные изменения, выпускать следующую beta APK.

## Оценка сроков
Параллелизация — стратегия ускорения, не обещание фиксированного процента. Оценку обновлять по результатам сборок, тестов, размера моделей и фактической сложности интеграции.
